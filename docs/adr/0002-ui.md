# ADR 0002: Avalonia and Skia

**Decision:** Use Avalonia 12.1 with its Skia backend, a shared application project, desktop bootstrap, Android bootstrap, and one stable custom timeline control.

**Alternatives:** MAUI/WinUI would preserve prototype coupling or make cross-platform behavior secondary.

**Consequences and validation:** Core projects reference no UI assembly. Rendering and interaction transforms are separately property-tested.
