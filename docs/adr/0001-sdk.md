# ADR 0001: SDK and upgrade policy

**Decision:** Pin stable .NET SDK `10.0.101` with roll-forward disabled. Nullable analysis, recommended analyzers, deterministic output, and warnings-as-errors apply repository-wide.

**Alternatives:** Floating SDKs and .NET 8/9 were rejected because reproducibility and the Avalonia 12 mobile support line require .NET 10.

**Consequences and validation:** Contributors install the exact SDK. Upgrades require a dedicated change with green cross-platform builds and benchmark comparison.
